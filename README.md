# Итоговый проект спринта 2

## Описание

Стартовый репозиторий для проекта по параметризации и фикстурам.

В проекте необходимо:
- создать тестового курьера через API;
- использовать фикстуру с `yield` для подготовки и очистки тестовых данных;
- написать параметризованный тест авторизации курьера;
- вынести общие фикстуры в `conftest.py`.

## Установка

Создайте виртуальное окружение и установите зависимости:

```bash
pip install -r requirements.txt
```

Создайте файл `.env` на основе `.env.example` и при необходимости измените `BASE_URL`.

## Запуск

```bash
python -m pytest -v
```

## API

Документация API доступна по адресу:

https://qa-scooter.praktikum-services.ru/docs/

Основные эндпоинты проекта:

- `POST /api/v1/courier` — создание курьера;
- `POST /api/v1/courier/login` — авторизация курьера;
- `DELETE /api/v1/courier/{id}` — удаление курьера.
